# Чугунный Лорд — офлайн-проект Android

Это подготовленный проект на React + Vite + Capacitor. Изображения заменены локальными SVG-заглушками, чтобы приложение не обращалось к Base44 при запуске. Рекорд хранится в `localStorage` на устройстве.

## Сборка APK на компьютере

Нужны Node.js 20+, Android Studio и Android SDK.

1. Распакуйте архив.
2. В папке проекта выполните `npm install`.
3. Выполните `npm run build`.
4. Выполните `npx cap add android` (только первый раз).
5. Выполните `npx cap sync android`.
6. Выполните `npx cap open android`.
7. В Android Studio выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

APK будет создан Android Studio в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Офлайн

- Игровой код, интерфейс и иллюстрации включаются в приложение локально.
- APK не требует интернет-соединения для запуска игры.
- Рекорд сохраняется локально на устройстве.
- PWA service worker также кэширует ресурсы после первой онлайн-загрузки браузерной версии.

## Примечание

В этом архиве нет собранного APK: для его компиляции нужен Android SDK/Android Studio. Текущая среда не содержит Android SDK. Визуалы портрета и здания заменены локальными иллюстрациями, так как оригинальные картинки в переданных исходниках представлены только внешними URL и не приложены файлами.
